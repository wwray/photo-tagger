🛰️ Location history

Fill in photos that have no GPS

What this is: if your phone logged a location history — a Google Takeout export, or a GPX track from a GPS watch or tracking app — PhotoTagger can use it to guess where a photo was taken when the photo itself has no GPS. It works by matching each photo's timestamp to the closest recorded point in time.

Why it's worth using: it's based on where you actually were, not a guess from a nearby photo's location or folder name — so it's usually more accurate than the automatic "Inferred" matches. It also runs entirely offline: no data leaves this server, and no API key is needed.

  1. Import a history file below (once — it's saved for reuse).
  2. Match it against your current library.
  3. Review the matches in the grid, same as any other suggestion — nothing is written to a file until you save.
